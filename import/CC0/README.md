# import/CC0/

Editions in the public domain or under CC0 1.0. Their configuration (`edition.yaml`, a
`README.md`, a sync script) is in git; their text may be too, unless it is synced or fetched
from its source, which the edition's `.gitignore` then keeps out. They can be used for
anything, including a revision whose result goes into `export/` (public domain).

Record in `edition.yaml`: `source` (where the files came from) and `licence` (for
example `public domain` or `CC0 1.0`, with a link to the statement).
