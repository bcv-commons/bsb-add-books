# import/non-free/

Editions that may not be published with this repository: all rights reserved,
unclear licences, non-commercial (NC) or no-derivatives (ND) licences, permission
for private use only, and for now any other open licence than CC0, CC BY and CC BY-SA. Their texts are
git-ignored and stay on the local machine: `text/`, `source/`, `quarantined/` and any other data file.
Only each edition's description is in git: `edition.yaml`, a `README.md`, and our own build scripts
(`*.py`), so that a clone knows the edition, its licence and its credit line, and the tools can say
what is missing. Keep these files free of the text itself and of private details.

Such editions can serve as a style corpus for private drafting. Record in
`edition.yaml` where they came from and under what terms (`licence: private use only`
if unclear). Revising one into `export/` is refused, because `export/` is public domain.
