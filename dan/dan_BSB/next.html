Read Daniel 12 with someone who knows Danish (dansk)

Open the chapter and switch to Verse by verse: each verse with the Hebrew, the BSB and the drafting agent's comments. The open questions from its notes:

  • `{H: Matt 24,21; Mark 13,19}` ved v1: tilpasset citat snarere end ordret – beholdes, eller flyttes til noterne som hentydning?
  • v1 »står vagt over« (BSB) eller ordret »står over« / »står frem for« (forsvarer)?
  • v4 »fare frem og tilbage« – eller »granske« (positiv tolkning) / »fare vild«?
  • v7 slutsætningen: følge MT (folkets magt knuses) som nu, eller rettelsen (undertrykkerens magt knuses)?
  • Skal v1-3 sættes som poesi (`//N`)? Mange oversættelser gør det.
  • v12 »når frem til de 1335 dage« – bestemt form (»de«) tilføjet for flydende dansk; ordret »når til 1335 dage«.

Corrections go into the chapter or the language memory; Claude Code makes them when asked:

Correct Daniel 12 in dan/dan_BSB: …

Show it to others: the website

The public website shows every project's drafts, marked as drafts, with the language memory and the credits; the text of a non-free translation never appears there, only short quotes within the limits. To put this project there, the files go into git and the site is deployed:

git add export/ import/ && git commit -m "…" && git push
python3 scripts/deploy_site.py

Or ask Claude Code to prepare it (it stages the files and gives you a commit message; you commit):

Stage dan/dan_BSB for the website and give me a commit message
