# Ruth 1: style revision

- v2: "Ngenek ezoqam-qa iz, Elimelék." → "Teqa iz Elimelék."; dropped the repeated "Ta manqei-te ndøgo," before "Ndigu mo-manqei-aním mbá" (place already given by "ndǿgo vø̄qom"). Model: JHN 1:6 "Teqa iz Zión."
- v3: "Elimelek, Neomi-ge zivis" → "Elimelek, ndego Neomi-ge zivis" (apposition with ndego). Model: REV 15:3 "Mozes-qá ouv..., ndego Mbumbukiam-ge sasae ezoqam"; JHN 21:2 "Natanael, ndego Keina vemiav-ak".
- v6: "ivav-qa" (not in corpus) → "ivøve-qa"; dropped "Zuda manqei-te nqawa veseze-qa" (the Hebrew of v6 has only "returned from the fields of Moab"; Judah stays in v7). Model: 1CO 7:15 "zas ivøve-qa tegoat".
- v8: speech intro "āv guzømbe-eín nqǽgo" → "manqat nøme āv guzømbe-eín nqǽgo". Model: JHN 16:25 "Yaq Yesu tegi paev ezoqam, manqat nøme āv gezømbe-eín nqǽgo".
- v20: "Mbumbukiam Bazaføgakh-qape" → "Mbumbukiam, ndego bazaføgakh ate ndægo ndømbogo" (Shaddai, the Almighty). Model: REV 16:14, REV 19:15 ("Mbumbukiam, ndego bazaføgakh ate ndægo ndømbogo"), REV 1:8, 2CO 6:18.
- v21: same change for the second "Mbumbukiam Bazaføgakh-qape". Model: as v20.
- v22: "gunduqavan" (not in corpus) → "gunøqaván" (she returned). Model: JHN 11:28 "tugu namba qawan-té gunøqaván".

Changed verses: 7 (v2, v3, v6, v8, v20, v21, v22).

Left as they were (no corpus backing found): v16 "nøpòuwe᷄" (prohibitive with 1sg object), v17 "bètá", v18 "gunigō", v22 "pea ndøngazém". The remaining *manqei -te* hits are land names the Hebrew repeats (v1 famine phrase follows LUK 15:14). No fitting place found for *nqanek*.
