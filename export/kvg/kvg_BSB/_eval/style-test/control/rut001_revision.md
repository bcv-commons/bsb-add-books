- v8: "Zo nango tozovesez" -> "Zo nqawa tozovesez" ("go back"; "nango" + vesez never occurs) - LUK 7:22 / MAT 11:4 "Zion-te nqawa tozovesez".
- v9: "Yaq ndugu guzø-ngenøtam" (unattested form) -> "Yaq ndugu ndigu sasa ndøngenøtam" - MAT 26:49, LUK 15:20, MRK 9:36 "sasa ndøngenøtam".
- v11: "Nango tozovesez" -> "Nqawa tozovesez" - LUK 7:22.
- v12: "Nango tozovesez" -> "Nqawa tozovesez" - LUK 7:22.
- v14: "tu-te gùmu-tøkenøvém" (unattested) -> "tu-te gèmø-tøkenøvém" (gè- completive takes no gender prefix) - ACT 3:11, ACT 8:13 "Filip-te, gèmø-tøkenøvém".
- v15: "nango gunøvesez" -> "nqawa gunøvesez" - ACT 7:39 "Izip manqei-te nqawa vesezam-qa", ACT 13:42 "nqawa vesezu".
- v16: "nango vø̄-vesēz" -> "nqawa vø̄vesēz" - ACT 1:12 "Zelusalem taon-te vø̄vesez" (forms: vø̄vesez 2) plus LUK 7:22 for nqawa.
- v19: "vømø̄-fakhaz" -> "vømø̄fakhaz" (attested form, 8 times) - 2TI 1:17 "atema vømø̄qand" for the atema construction; forms list "vømø̄fakhaz".
