# Wortschatz: wo das Korpus anders spricht als das Hochdeutsche

Die Einträge unten nennen das Wort des Korpus für einen englischen Begriff der BSB, mit Anteil und
Belegen. Was ein Agent ohne diese Liste falsch machen würde:

| Begriff (BSB) | Korpus | hochdeutsche Form im Korpus |
|---|---|---|
| see / look, behold | gseh / luege, lue!, lueget! | sehen, schauen 0× |
| listen / hear | lose (»Loset!«) / ghöre | zuhören 0× |
| weep | briegge (»lut briegge«) | weinen 0× |
| kiss | es Müntschi gä | küssen 0× |
| marry | hürate | heiraten 0× |
| girl / boy | Meitschi / Bueb | Mädchen, Junge 0× |
| always / only / also / now | geng / nume / o / jitz | immer, nur, auch, jetzt 0× |
| because / therefore | wil / drum | weil, darum 0× |
| today / tomorrow / yesterday | hütt / morn / geschter | heute, morgen 0× |
| money | Gäld | Geld 0× |
| king | Chünig | König 0× |
| brothers (Anrede) | Gschwüschterti | – |
| blessed (Seligpreisung) | glücklech | selig 0× |
| repent | sech ändere (»Änderet nech!«) | Busse tun 0× |
| church | Gmeind | Kirche 0× |

Weitere Kennwörter: Härz, Ouge, Liecht, Fyschteri, Füür, Zyt, Wält, Ärde, Himel, Huus, Frou (auch
Ehefrau), Maa (auch Ehemann; Pl. Manne), Chind (Pl. Chinder), Suhn (Pl. Sühn), Vatter, Mueter,
Schwöschter, Gloube, Gsetz, Sünd, Tämpel, Prieschter, di gueti Botschaft.

Vor einer eigenen Bildung immer suchen: `python3 scripts/concord.py ch-de-be/ch-de-be_BSB lex <englisches Wort>`
und `… forms <Muster>`. Wörter, die nicht im Korpus sind, im Notizfile als »nicht belegt« melden.


Fallen, die das Hochdeutsche stellt: ›Wind‹ heisst »Luft« (der Luft, ACT 27:13), ›Mund‹ »Muul«,
›Honig‹ »Hung« (nicht Hund), ›zornig‹ »toub«, ›weise‹ »gschyd«. »Hoheprieschter« ist der eine
Hohepriester, »Oberprieschter« die Oberpriester (je 41×). Die Ältesten der Gemeinde sind
»Gmeindsvorstand«, die jüdischen »Ratsherre«.
