===Genesis, Chapter 1===

==Ou Gad Mek Evriting==

v1 Wen taim did staat, Gad mek di evn an di ort. v2 Nou di ort
neva av no shiep, an it did emti. Daak did kova di diip waata,
an Gad Spirit did a flai uova di waata.

==Di Fos Die==

v3 Den Gad se, “Mek lait de!” An lait kom. v4 Gad si se di lait gud,
an im plit di lait fram di daak. v5 Gad kaal di lait “Die,”
an di daak im kaal “Nait.” Iivnin kom, an maanin kom: dat a did di
fos die.

==Di Sekan Die==

v6 Gad se, “Mek wan big ruuf de iina di migl a di waata, fi
plit di waata fram di waata.” v7 So Gad mek di ruuf, an im
plit di waata we de anda di ruuf fram di waata we de
uova it. An a so it apm. v8 Gad kaal di ruuf “Skai.” Iivnin
kom, an maanin kom: dat a did di sekan die.

==Di Tord Die==

v9 Gad se, “Mek di waata we de anda di skai gyada tugeda iina wan
plies, an mek di jrai lan kom out.” An a so it apm. v10 Gad
kaal di jrai lan “Ort,” an di waata we gyada tugeda im kaal “Sii.”
An Gad si se it gud. v11 Den Gad se, “Mek di ort bier griin
tingz: plaant we bier siid, an evri fruut chrii we bier fruut wid
siid iina it, difrant difrant kaina, pan di ort.” An a
so it apm. v12 So di ort bier griin tingz: plaant we bier siid,
difrant difrant kaina, an chrii we bier fruut wid siid iina
it, difrant difrant kaina. An Gad si se it gud. v13 Iivnin
kom, an maanin kom: dat a did di tord die.

==Di Fuot Die==

v14 Gad se, “Mek lait dem de iina di skai ruuf, fi plit di die
fram di nait. Dem ago bi sain fi shuo di siizn dem,
di die dem an di ier dem. v15 Mek dem shain iina di skai ruuf
fi gi lait pan di ort.” An a so it apm. v16 Gad mek tuu
big lait: di biga lait fi ruul di die, an di likla
lait fi ruul di nait. Im mek di staar dem tu. v17 Gad put
dem iina di skai ruuf fi gi lait pan di ort, v18 fi ruul uova
di die an di nait, an fi plit di lait fram di daak. An
Gad si se it gud. v19 Iivnin kom, an maanin kom: dat a did di fuot
die.

==Di Fif Die==

v20 Gad se, “Mek di waata ful op wid nof nof sitn we liv, an mek
bod flai uova di ort, kraas di skai ruuf.” v21 So Gad mek di
big big animal dem iina di sii. Im mek aal kaina sitn we liv an
muuv bout, we di waata ful op wid, difrant difrant kaina.
An im mek evri bod we av wing, difrant difrant kaina. An
Gad si se it gud. v22 Gad bles dem an se, “Unu av nof nof
pikni, an ful op di waata iina di sii dem, an mek di bod
dem ton nof nof pan di ort.” v23 Iivnin kom, an maanin kom: dat a
did di fif die.

==Di Siks Die==

v24 Gad se, “Mek aal kaina sitn we liv kom out a di ort: animal
we piipl kip, animal we kraal pan di grong, an wail animal
pan ort, difrant difrant kaina.” An a so it apm. v25 Gad
mek di wail animal dem pan ort, difrant difrant kaina, di animal
dem we piipl kip, difrant difrant kaina, an evriting we kraal
pan di grong, difrant difrant kaina. An Gad si se it gud.
v26 Den Gad se, “Mek wi mek piipl fi luk laik wi, fi bi laik wi.
Mek dem ruul uova di fish iina di sii, di bod iina di
skai, di animal dem we piipl kip, di uol ort, an
evri sitn we kraal pan di ort.”

//1 v27 So Gad mek piipl fi luk laik imself;

v28 Gad bles dem an se tu dem se, “Unu av nof nof
pikni, an ful op di ort an tek kanchuol a it. Ruul uova
di fish iina di sii, di bod iina di skai, an evri
sitn we liv an muuv pan di ort.” v29 Den Gad se, “Luk ya, mi
gi unu evri plaant we bier siid pan di uol ort, an evri
chrii we av fruut wid siid iina it. Dem ago bi fi
unu fuud. v30 An tu evri wail animal pan di ort, tu evri bod iina
di skai, an tu evriting we kraal pan di ort — evriting we av
di bret a laif iina dem — mi gi evri griin plaant fi nyam.”
An a so it apm. v31 Gad luk pan evriting we im did mek, an si
se it wel gud. Iivnin kom, an maanin kom: dat a did di siks die.
