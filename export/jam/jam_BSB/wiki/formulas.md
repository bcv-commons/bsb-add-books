# Formulas

Recurring phrases of the Hebrew narrative and their models in the corpus.

| Hebrew / BSB | corpus | model |
|---|---|---|
| he said to X | X se tu Y se, “…” | LUK 15:7 (355×) |
| answered | ansa (X) se | MAT 4:7 |
| asked | aks X se | ACT 2:12 |
| let us | Mek wi + verb | MRK 1:38 |
| let there be | Mek + subject + verb | 2CO 4:6 |
| do not be afraid | No fried | LUK 1:13 (38×) |
| declares / says the LORD | di Laad se | HEB 8:8, ACT 7:49 |
| the LORD said to X | Di Laad se tu X se | MAT 22:44 |
| named X | wan man niem X; we dem kaal X | ACT 8:9, ACT 3:2 |
| called his name X | kaal im X | MAT 1:21 |
| X fathered Y | X a did Y faada / Y a did X pikni | MAT 1:2, LUK 3:34 |
| in the beginning | Wen taim did staat | JHN 1:1 |
| forever (and ever) | fi eva (an eva) | REV 10:6 |
| the next day | di neks die | ACT 4:3 |
| after these things | Afta dat | LUK 1:24 |
| God saw that it was good | Gad si se it gud (by rule) | 1TI 4:4 |

Genesis 1 (first draft, 2026-10-16) fixed the creation refrains; they are proposals for the team, reused
verbatim wherever the Hebrew repeats them:

| Hebrew / BSB | draft | built from |
|---|---|---|
| And it was so | *An a so it apm.* | focus *a* + *so*; "So it apm" (JAS 2:23) |
| And there was evening, and there was morning: the Nth day | *Iivnin kom, an maanin kom: dat a did di N die.* | "Wen iivnin kom" (MAT 8:16); past copula *a did* |
| God called X "Y" | *Gad kaal X “Y”*; a fronted object stays first: *an di daak im kaal “Nait”* | |
| according to its kind | *difrant difrant kaina* | 1CO 15:38 |
| in our image, after our likeness | *fi luk laik wi, fi bi laik wi* | REV 15:2 |
| Be fruitful and multiply | *Unu av nof nof pikni* | the gap proposal |
